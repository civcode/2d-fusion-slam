# Offline fusion replay runs

This directory is a read-only source for the native Web UI's **Fusion Replay**
page at `/fusion` when started with Docker Compose.

Generate a real native synthetic offline run from the project root:

```sh
cmake --build build --target slam_offline_fusion
./build/slam_offline_fusion apartment apps/demo/fusion/apartment-001
./build/slam_offline_fusion warehouse apps/demo/fusion/warehouse-001
docker compose up --build demo
```

Open http://127.0.0.1:8765/fusion. Output directories must not already
exist; new runs are never overwritten. For non-Docker use, start
`fusion_slam_demo --data-dir apps/demo/maps --fusion-dir apps/demo/fusion`.
The server reads artifacts only; all source files remain outside the
container image and are mounted read-only.

Only direct child directories named with ASCII letters, digits, hyphens or
underscores are exposed, with `fusion_report.json`, `trajectories.json`
and `fusion_replay.json` generated by the same native run. A missing or
invalid artifact fails closed. No live SLAM process or robot controls exist.
